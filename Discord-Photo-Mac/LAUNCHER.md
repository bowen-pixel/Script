# Discord Themes：Mac启动器

你的朋友提供的例子是AppleScript启动器，不是CSS。本工具也用本机编译的AppleScript .app作为入口，主题渲染仍由Node脚本完成。

## 安装和日常使用

1. 完整解压文件夹。Node.js须为22+，Python须为3.9+。
2. 双击 `Install Discord Themes.command`；仅安装时打开一次终端。
3. 在Finder的个人Applications文件夹找到 `Discord Themes.app`。以后双击它即可，不需要每天运行命令。
4. 选择“选择主题并启动 Discord”，再选择喜欢的主题。

本机安装位置：`~/Applications/Discord Themes.app`。可拖到Dock，或者用Spotlight搜索Discord Themes。

如果Discord已经由本启动器以主题模式运行，选择另一主题会直接切换并验证图片及布局。普通Discord正在运行时，启动器会先说明退出重开会中断语音、直播和未保存操作；取消不会重开或更改主题。检测到别的工具的调试会话时，会提示先用原工具恢复。

## 菜单功能

| 菜单 | 做什么 |
| --- | --- |
| 选择主题并启动 Discord | 选择已保存主题，或继续上次选择 |
| 导入主题 ZIP | 系统文件选择框；验证并保存后，可选择立即启动 |
| 用我的照片创建主题 | 选图、输入名称，创建独立的已保存主题；不覆盖当前配置 |
| 浏览 / 下载在线主题 | 默认搜索Miku，可改搜索词、翻页或留空浏览；选择一项下载 |
| 检查在线主题更新 | 比较已记录的在线来源，选择更新一套或全部；保存后再手动应用 |
| 导出当前主题 ZIP | 系统保存框，导出可重新导入的完整包 |
| 恢复普通 Discord | 说明重启影响后，退出主题实例并重开普通Discord |
| 打开已保存主题文件夹 | 在Finder查看启动器的主题库 |
| 查看状态 | 显示普通／主题模式、当前选择及保存数量 |

下载仍执行固定官方API、包大小、SHA-256、ZIP/manifest与Safe CSS检查。网络失败不会被当作“已更新”。更新的是库内副本，当前画面使用的配置快照保持不变。导入本地ZIP或个人照片的条目没有自动在线更新来源。

## 主题库、升级和卸载

- 持久库：`~/Library/Application Support/Discord Theme Launcher`。
- 安装器从旧脚本文件夹的 `.discord-photo-runtime` 复制尚未存在的照片和主题，不迁移PID、端口或后台日志。之后两个库独立。
- 升级工具：先关闭启动器菜单，恢复正在运行的主题，再解压新包并重新运行安装器。仅替换身份匹配的本启动器，不覆盖已保存的同名主题／当前设置。
- Node或Python原来安装的路径被删除时，重新安装相应运行时，再运行本工具安装器以更新路径。
- 移动.app不影响库；仍需保留Node和Python。把.app复制到另一台电脑不能代替在那台电脑安装。
- 卸载前先用菜单恢复普通Discord。删除.app会保留主题库；要一并删除自己的素材，手动删除上述Application Support文件夹。

如果菜单无响应或启动报错，可查看库中的 `launcher.log`。日志不记录聊天正文，但可能有你选的主题名称及本机错误路径，分享前检查内容。
