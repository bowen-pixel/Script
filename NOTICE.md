# Sources and scope

The Bilibili userscript and macOS launcher are the existing learning-project implementations, copied without local runtime state. Earlier inspiration included Crystallis's archived YouTube Sonic progress-bar theme; its original stylesheet is not bundled here. The two minimal browser CSS adapters are newly written for this packaging.

The character GIF and the character visible in recorded demos are third-party artwork. No ownership or redistribution license for that artwork is granted here. The scripts support selecting replacement artwork. The repository makes no affiliation claim with YouTube, Bilibili, or the character owner.

Only source files, instructions, and selected demo images are published. Local sessions, logs, private configurations, and application profiles are excluded.
